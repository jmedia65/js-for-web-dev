# JavaScript for Web Dev

Learn JavaScript for modern web development — from fundamentals to building full-stack applications with React and FastAPI.

A beginner-friendly course that teaches the 20% of JavaScript you'll use 80% of the time, with practical examples and real-world patterns.

## What You'll Learn

- **JavaScript Core** — Variables, functions, async/await, and essential language features
- **Working with Data** — Arrays, objects, JSON, and data manipulation
- **Async & APIs** — Making HTTP requests, handling responses, error handling
- **DOM & Browser** — DOM manipulation, events, forms, and local storage
- **React Essentials** — Components, state, effects, and practical patterns
- **Full-Stack Integration** — Connecting React to FastAPI, CRUD operations, production patterns

---

## Who This Is For

**This course is for you if** you know Python and want to learn JavaScript for web development. Every concept includes Python comparisons so you can map what you already know to how JavaScript does it. Ideal if you're building full-stack apps with FastAPI and need to learn the frontend.

**This course is NOT for you if** you're completely new to programming (start with Python first), you want advanced React patterns (Context, Reducers, etc.), or you want to learn Vue, Angular, or other frameworks.

## Course Philosophy

Most JavaScript courses either teach everything (overwhelming), skip critical concepts (leaving gaps), focus on theory (not practical), or ignore the backend connection (React in isolation).

This course is different:

- **Code first, explain after** — Every concept starts with a working example. Explanations come after, not before.
- **The 20% you'll use 80% of the time** — Only practical patterns you'll use in real projects. Advanced topics are acknowledged but not deeply covered.
- **Realistic examples** — No `foo`, `bar`, or `example123`. All examples use realistic data and scenarios.
- **Common mistakes highlighted** — Every major concept includes a section showing what NOT to do and why.
- **Python comparisons throughout** — Side-by-side comparisons so you can map what you already know (template literals vs f-strings, `.map()` vs list comprehensions, etc.).

After completing this course, you should be able to build interactive web UIs with React, connect to FastAPI backends with proper error handling, and structure full-stack applications professionally. You won't know everything about JavaScript, but you'll know enough to build real applications and learn the rest as you go.
