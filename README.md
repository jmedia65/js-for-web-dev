# JavaScript for Web Dev

Learn JavaScript for modern web development — from fundamentals to building full-stack applications with React and FastAPI.

A beginner-friendly course that teaches the 20% of JavaScript you'll use 80% of the time, with practical examples and real-world patterns.

## What You'll Learn

- **JavaScript Core** — Variables, functions, async/await, and essential language features
- **Working with Data** — Arrays, objects, JSON, and data manipulation
- **Async & APIs** — Making HTTP requests, handling responses, error handling
- **DOM & Browser** — Manipulating web pages, handling events, browser APIs
- **React Essentials** — Components, state, effects, and practical patterns
- **Full-Stack Integration** — Connecting React to FastAPI, CRUD operations, production patterns

---

## Who This Is For

**This course is for you if** you know Python and want to learn JavaScript for web development, you're building full-stack apps with FastAPI and need to learn the frontend, or you prefer practical, hands-on learning over theoretical deep dives.

**This course is NOT for you if** you're completely new to programming (start with Python first), you want advanced React patterns (Context, Reducers, etc.), or you want to learn Vue, Angular, or other frameworks.

## Course Structure

The course is divided into 9 main sections:

1. **Introduction** - What you'll learn and how to use this course
2. **Getting Started** - Node.js, VS Code, npm, and project setup
3. **JavaScript Core** - Variables, functions, scope, and language fundamentals
4. **Working with Data** - Arrays, objects, JSON, and control flow
5. **Async & APIs** - Promises, async/await, fetch, and error handling
6. **DOM & Browser** - DOM manipulation, events, and browser APIs
7. **React Essentials** - Components, state, effects, and practical patterns
8. **Full-Stack Integration** - Connecting React to FastAPI with real examples
9. **Next Steps** - Where to go from here, resources, and deployment

## Writing Style and Philosophy

This course follows specific principles to maximize learning efficiency:

### Code First, Explain After

Every concept starts with a working code example. Explanations come after, not before.

### The 20% You'll Use 80% of the Time

We focus on practical patterns you'll use in real projects. Advanced topics are acknowledged but not deeply covered.

### Realistic Examples

No `foo`, `bar`, or `example123`. All examples use realistic data and scenarios you'll encounter in actual web development.

### Common Mistakes Highlighted

Every major concept includes a "Common Mistakes" section showing what NOT to do and why.

### Python Comparisons (When Helpful)

Since the target audience knows Python, we compare concepts where it aids understanding (template literals vs f-strings, etc.).

## Course Philosophy

### Why This Course Exists

Most JavaScript courses either:

1. Teach everything (overwhelming for beginners)
2. Skip critical concepts (leaving gaps in understanding)
3. Focus on theory (not practical application)
4. Ignore the backend connection (React in isolation)

This course is different:

- **Focused**: Only what you need to build real web apps
- **Practical**: Every concept demonstrated with working code
- **Connected**: Shows how frontend and backend work together
- **Efficient**: Respects your time by teaching the essential 20%

### Target Outcome

After completing this course, you should be able to:

- Build interactive web UIs with React
- Connect to FastAPI backends with proper error handling
- Understand async JavaScript and work with Promises
- Manipulate the DOM and handle user events
- Structure full-stack applications professionally
- Debug JavaScript code effectively

You won't know everything about JavaScript, but you'll know enough to build real applications and learn the rest as you go.
